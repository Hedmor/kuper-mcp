# Разработка

Используйте Node.js 22.18+ и pnpm 12.10.1 из packageManager.

```sh
pnpm install --frozen-lockfile
pnpm run dev
pnpm run format
pnpm run check
```

Без глобального pnpm: `npm exec --yes --package=pnpm@12.10.1 -- pnpm <команда>`.

## Правила изменений

- stdout зарезервирован для MCP JSON-RPC; логи пишите через console.error.
- Комментируйте на русском причины решений, ограничения API и неочевидные вычисления.
- Не заменяйте неизвестные цену, наличие или массу нулём либо вымышленным значением.
- ID передавайте строками; деньги округляйте на границах расчёта.
- Проверяйте новое поведение тестами. Сетевые запросы не включайте в обычный test/check.
- Обновляйте документацию при изменении конфигурации или ответа инструментов.
- Обновляйте pnpm-lock.yaml при изменении зависимостей.

## Перед публикацией

Выполните `pnpm run check`, `docker build -t kuper-mcp:local .` и
`node scripts/smoke-docker.mjs` при доступном Docker Engine.
Убедитесь, что .env, cookies, локальные отчёты, node_modules и dist не добавлены в Git.
.gitignore и .dockerignore исключают локальные данные.

Smoke контейнера проверяет протокол без сети. Для добровольной проверки живого каталога
задайте KUPER_SMOKE_LAT/KUPER_SMOKE_LON своего адреса и выполните `pnpm run scrape:smoke`.
Он читает одну страницу магазинов и одну страницу поиска, не весь каталог.
